# Презентація — PoC: Аудіо → Speech-to-Text → Gemini

Юлія Частухіна · Хмарні обчислення · Завдання 2
Хмара: **Google Cloud Platform**

---

## Слайд 1. Титул

**Розумний конспектувальник аудіо**
Сервіс, що перетворює аудіозапис (лекцію, зустріч, голосову нотатку) на
структурований текстовий конспект за допомогою хмарних AI-сервісів Google Cloud.

---

## Слайд 2. Суть проєкту та де застосовувати

**Проблема.** Години аудіо (лекції, наради, інтерв’ю) ніхто не переслуховує — з них
важко швидко дістати головне.

**Рішення.** Завантажуєш аудіо → отримуєш: повну розшифровку + короткий зміст +
ключові тези + список завдань (action items).

**Де застосовувати:**
- студенти — конспекти лекцій;
- бізнес — протоколи зустрічей і список доручень;
- журналісти — розшифровка інтерв’ю;
- підтримка/продажі — аналіз дзвінків.

---

## Слайд 3. Які API використовуються

| Сервіс | Роль у проєкті |
|---|---|
| **Google Cloud Speech-to-Text API** | розпізнавання мови: аудіо → текст (uk-UA, автопунктуація) |
| **Gemini API** (`gemini-1.5-flash`) | підсумовування: транскрипт → структурований конспект |
| **Cloud Run** | serverless-хостинг контейнера (автоскейл, HTTPS «з коробки») |
| **Artifact Registry** | зберігання Docker-образу сервісу |
| **IAM / Service Account** | доступ Cloud Run до Speech-to-Text без ключів у коді |

Застосунок — **FastAPI** (Python), один ендпоінт `POST /process`.

## Слайд 4. Взаємодія між сервісами

```
   Користувач
      │  (1) POST /process  — аудіофайл (multipart)
      ▼
┌──────────────────────┐
│  Cloud Run            │  FastAPI-контейнер
│  (сервіс speech-poc)  │
└──────────┬───────────┘
           │ (2) RecognitionAudio(bytes)
           ▼
   ┌───────────────────────┐
   │ Speech-to-Text API     │ ── (3) transcript ──┐
   └───────────────────────┘                      │
           ┌───────────────────────────────────────┘
           │ (4) prompt + transcript
           ▼
   ┌───────────────────────┐
   │ Gemini API             │ ── (5) summary ─────┐
   └───────────────────────┘                      │
           ┌───────────────────────────────────────┘
           ▼
   (6) JSON { transcript, summary }  →  Користувачу
```

- **(1)** клієнт надсилає аудіо на HTTPS-ендпоінт Cloud Run;
- **(2–3)** сервіс передає байти в Speech-to-Text, отримує транскрипт;
- **(4–5)** транскрипт + промпт ідуть у Gemini, що повертає конспект;
- **(6)** користувач отримує JSON з розшифровкою та конспектом.

Автентифікація: Cloud Run працює під **сервісним акаунтом** (ADC), тому ключі GCP не
зберігаються у коді; ключ Gemini — у змінній середовища `GEMINI_API_KEY`.

## Слайд 5. Демонстрація результатів

> **Відео демонстрації:** `demo/demo.mp4` — вставити у презентацію (або коротке realtime demo на парі).

Приклад виклику:
```bash
curl -X POST https://<cloud-run-url>/process \
     -F "audio=@lecture.wav"
```

Приклад відповіді:
```json
{
  "transcript": "Сьогодні розглянемо закон Амдала та масштабування паралельних програм...",
  "summary": "Короткий зміст: лекція про межі прискорення...\n• Закон Амдала...\n• Action items: прочитати розділ 4"
}
```

Локальний запуск сервісу (перевірено — health 200 OK):
```bash
docker build -t speech-gemini-poc .
docker run -p 8080:8080 -e GEMINI_API_KEY=... speech-gemini-poc
```
