# parcs-py — мінімальний рантайм PARCS-Python

Сумісна з PARCS-Python (Hummer12007) реалізація рантайму нод на Pyro4, щоб кластер
піднімався однією командою `docker compose up` без ручного складання фреймворку:

- `master.py` — піднімає/знаходить Pyro4 nameserver, збирає зареєстрованих воркерів,
  передає їх у `Solver(workers, input, output)` і запускає `solve()`.
- `worker.py` — реєструє Worker-демон у nameserver і віддає обчислення методу
  `Solver.mymap` з джоби.

Джоба (`../solver.py`) написана за стандартним шаблоном PARCS-Python (клас `Solver`
з `@expose`-методами), тож її можна запускати і на оригінальному фреймворку: достатньо
покласти його вихідники в цю теку замість цих двох файлів.
